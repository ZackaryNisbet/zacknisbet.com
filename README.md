# zacknisbet.com

Canonical personal website for Zack Nisbet, built as a static site and deployed on Vercel.

## Local development

```sh
npm run start
```

Then open `http://localhost:4173`.

## Checks

```sh
npm run check
```

## Deployment

The production domain is `https://zacknisbet.com/`.

`zackarynisbet.com`, `www.zacknisbet.com`, and `www.zackarynisbet.com` redirect to the canonical domain through Vercel.
