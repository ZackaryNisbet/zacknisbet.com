Privacy

Personal automation tools · Last updated 16 September 2026

Zack Nisbet builds small private tools that automate his own administrative work — for example an expense tool that reads his own email for receipts and prepares his own expense reports. This page explains what those tools do with data. They are personal software, run by one person, for that person's own accounts.

Who this covers

These tools are not products. They are not offered to, sold to, or usable by anyone else. There are no other users and no accounts to create. Each tool runs on Zack Nisbet's own computer and is authorised only against mailboxes and services he owns or administers.

What data is accessed

  • Email that the tool identifies as receipt- or invoice-shaped, read through Google's Gmail API with read-only permission, together with any attached receipts.
  • Calendar entries, read-only, where a tool uses them to describe the business purpose of an expense.
  • Information derived from the above: merchant, amount, date and category of a purchase.

Access is granted by Zack Nisbet signing in to his own accounts, or by an administrator authorisation for a Google Workspace domain he administers. No third party's account is accessed.

How the data is used

Only to do the task the tool exists for: find expenses, summarise them for review, and file the approved ones with the relevant expense system. The data is not used for advertising, profiling, model training, or any purpose unrelated to that task.

Where the data is stored

On Zack Nisbet's own machine. Credentials are held in the operating system's keychain and never written into source code or project files. Nothing is published, and no copy is sent anywhere except to the service the expense is being filed with.

Who the data is shared with

No one. Data is not sold, rented, or disclosed. The only outbound traffic is to the services the tool is explicitly pointed at, such as Google's APIs to read the mail and the expense system the report is filed with.

Retention and deletion

Collected records are kept only as long as they are useful for filing and reconciling expenses, and can be deleted at any time by deleting the tool's local data. Access can be withdrawn at any time from Google account permissions or by removing the administrator authorisation, which immediately stops all access.

Google user data

Use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.
